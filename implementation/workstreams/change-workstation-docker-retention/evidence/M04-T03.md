## Correction

The M04-T02 live attempt proved that the D26 passwordless steady state is blocked by
`scripts/preflight-host.sh` requiring `keyring-password` to be non-empty.

The correction changes only that stale readiness predicate:
- the migration placeholder must still exist as a regular file;
- empty content is accepted as the intended fresh/post-migration D26 state;
- non-empty legacy migration credentials remain accepted;
- a missing placeholder still fails host preflight.

A deterministic regression fixture,
`scripts/test-preflight-keyring-state.sh`, runs the real preflight script with fake
host commands and temporary paths and proves all three states. Source validation now
runs that fixture and guards against restoring the stale `-s` requirement.

The first implementation write accidentally encoded literal `\\n` sequences in
the preflight block. The new missing-placeholder fixture immediately caught that
the guard had become commented out. That intermediate state was corrected before
the subject was frozen; the final exact subject above contains executable separate
lines and passed the full test set.
