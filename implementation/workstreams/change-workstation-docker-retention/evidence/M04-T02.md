## Blocker

Host preflight then failed with:

`FAIL: missing/empty keyring secret: /mnt/user/appdata/chatgpt-ce-workstation/secrets/keyring-password`

and the updater reported:

`Update stopped before production mutation: host_preflight_failed`.

No candidate build, Docker/BuildKit cleanup, production recreate, keyring mutation or other production Docker mutation occurred in this attempt.

The failure is a source-level compatibility defect, not an operator/runtime-data defect:
- D26 and `scripts/init-unraid.sh` intentionally create/accept an **empty** keyring migration placeholder for fresh/passwordless state;
- `scripts/update.sh::finalize_keyring_passwordless_migration` intentionally truncates the legacy migration credential to an empty file after successful migration;
- `scripts/preflight-host.sh` still requires that same file with `-s` (non-empty), making a normal subsequent update impossible after successful passwordless migration.

M04-T02 forbids an ad-hoc live workaround when source changes are required. Live execution therefore remains blocked until this accepted-authority preflight contradiction is corrected, deterministically tested, independently reviewed, and the retry uses the corrected reviewed subject.
