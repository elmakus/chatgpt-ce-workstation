### Must preserve

- Production activation is forbidden until the running `codex-web-gpt` proves v5.0.13+ or equivalent direct evidence for both parallel Muse routing and the configured-upstream proxy-resolution fix.
- v5.0.10-v5.0.12 are not sufficient solely by version.
- If the running image is stale, use the existing repository-owned D25 `resolve -> freeze -> build -> validate -> promote` path first, then repeat the capability preflight.
- The Muse endpoint is `http://192.168.2.104:8317/v1`.
- `CODEX_CHATGPT_WEB_NATIVE_UPSTREAM` must remain unchanged.
- The CLIProxyAPI ingress key remains outside Git and outside Workstation `.env`; persist it only in the fork-owned `~/.config/codex-web-gpt/muse-proxy-api-key` under the persistent codex home.
- Never print, log, commit or place the key value into evidence.
- Do not intentionally degrade production to test Muse-catalog failure isolation. Use exact-release automated/source evidence when sufficient; otherwise use a bounded isolated/staged invocation.
- Existing `chatgpt-web/*` behavior and workstation health must remain functional.

### Must not / rationale that must travel

- Do not activate the Muse endpoint against a binary that lacks either required capability.
- Do not move Codex-LB behind CLIProxyAPI or import non-`muse-*` CLIProxyAPI rows.
- Do not create a second provider-routing implementation in Workstation.
- Do not use a production outage as the normal failure-isolation test.

## Outcome

The production Workstation reproducibly receives the optional CLIProxyAPI Muse endpoint, the persistent Muse ingress key is installed secret-safely, available `muse-*` models are discovered and routed through CLIProxyAPI, and existing Codex-LB plus `chatgpt-web/*` routes remain functional and isolated.

## Scope

### Included

- Secret-safe production capability/version preflight.
- Conditional D25 Workstation update/build/validate/promote when the current image lacks the required fork capabilities.
- Read the existing CLIProxyAPI ingress key from operator-managed configuration without emitting its value.
- Persist the key as the codex user's `~/.config/codex-web-gpt/muse-proxy-api-key` with restrictive permissions.
- Persist the non-secret Muse endpoint through the repository-owned Compose runtime path and recreate/restart the Workstation.
- Verify environment readback, key-file presence/ownership/mode, model discovery/filtering, ordinary native routing, one available `muse-*` route, browser-backed `chatgpt-web/*`, failure isolation, and Workstation health.
- Record secret-safe production evidence and rollback readiness.

### Excluded

- Changes to Muse Code / `muse-max` orchestration.
- Changes to CLIProxyAPI provider configuration beyond reading its existing ingress key.
- Changes to `codex-chatgpt-web` routing code.
- Deliberate production failure injection.
