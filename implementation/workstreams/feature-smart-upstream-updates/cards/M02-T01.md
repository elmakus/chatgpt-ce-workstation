### Must preserve

- `build.sh` is a lower-level exact/development primitive and must not independently resolve "latest".
- Candidate build consumes one already-frozen M01 resolution set; it must not silently re-resolve a different moving upstream and still succeed.
- Ubuntu stays on 24.04 and the Docker `FROM` consumes the frozen base digest.
- CE Git commit and official OpenAI package identity remain separate inputs; the OpenAI package continues through CE's signed repository/key/index/package-hash trust path.
- Existing checksum/authenticity paths for Codex Web GPT and other upstreams remain authoritative.
- Runtime self-updaters remain disabled.
- Candidate metadata is inspectable and secret-free.
- Production container is not recreated or mutated.

### Must not

- No `UPSTREAM_REFRESH`, timestamp, random nonce or global `--no-cache` freshness model.
- No fallback to moving branch/tag/channel values after the frozen manifest has been accepted.
- No weakening of isolation or checksum/signature verification.

## Dependencies

- `M01-T02`

## Outcome

The frozen M01 manifest is the single exact input contract for Docker/Compose candidate builds. Every managed upstream is bound to its resolved identity and the built image carries the exact provenance manifest.

## Scope

### Included

- Add a safe manifest-to-build-args bridge.
- Make `build.sh` require an explicit frozen resolution file and stage its non-secret provenance for the image.
- Bind Docker `FROM` to the exact Ubuntu base identity.
- Bind Ubuntu APT state, CE commit, OpenAI package, s6, Agent Workspace, Codex Web GPT, Muse, Chrome and Rust to the frozen identities and fail if live metadata no longer matches.
- Remove `UPSTREAM_REFRESH` from normal build semantics.
- Preserve/strengthen existing upstream checksum/signature paths.
- Embed the exact resolution manifest and resolution digest in the candidate image.
- Add fixture/static tests for manifest ingestion and exact build-arg wiring.

### Excluded

- Production recreation/promotion/rollback (`M03`/`M04`).
- Normal updater orchestration (`M03`).
- Live workstation deployment.

## Acceptance

- Same frozen manifest produces the same normalized build inputs/candidate tag seed.
- Every component identity is consumed by the relevant Docker layer/verification path.
- A changed/moved upstream cannot silently produce a successful candidate under an older frozen identity.
- `UPSTREAM_REFRESH` is absent from Dockerfile/Compose/build flow.
- OpenAI package is downloaded/verified through exact CE signed metadata before use.
- Image includes the exact non-secret resolution manifest and digest.
- Source validation and fixture tests are GREEN.
- No production write/recreate occurs.

## Required tests / checks

- manifest-to-build-args fixture tests;
- static checks for exact `FROM`, CE commit, expected hashes/versions and absence of `UPSTREAM_REFRESH`;
- `bash scripts/validate-source.sh`;
- Dockerfile buildx static check;
- no live workstation recreate.

`none` — the integrated M01-M02 subject is reviewed after M02-T02.
