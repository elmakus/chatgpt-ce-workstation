### Must preserve

- `codex_workflow` owns runtime/orchestration semantics only; it must not import or interpret Project Workflow Task Board, review-state or policy semantics.
- Existing semantic worker TOMLs remain canonical unless a concrete contradiction is discovered and escalated.
- Stable logical Muse `session_id` is distinct from unique per-turn `invocation_id` and private artifact identity.
- Session binding covers logical worker identity, role, active profile/allocation, canonical workspace, and opaque caller task/lane scope without interpreting the caller state machine.
- Executor and Tester always use distinct logical/session identities; Tester never performs production repair.
- A changed subject alone does not require a fresh Tester. Normal repair prefers A1 -> B1 -> A1 repair -> B1 full recheck when both sessions remain safe.
- Resume/recovery is fail-closed. Missing/unusable/busy/binding-invalid/rejected resume must not silently mint a replacement under the old logical identity.
- One session may have at most one active invocation; cross-role/workspace/lane session reuse is rejected.
- Existing normalized structured output, terminal validation, raw artifact isolation/permissions/retention, changed-path evidence, timeout/cancel process-tree cleanup and profile-aware routing remain intact.
- `plus`, `luna-xhigh`, and `pro-x5` behavior remains unchanged.
- Production `~/.codex/codex_workflow`, `codex_workflow:main`, release/version metadata and published releases must not be mutated by this Card.

### Must not / rationale that must travel

- Do not freeze the private session-registry file format, exact lock primitive, or exact native session-health probe beyond the accepted fail-closed semantics. They are L1/L2 implementation choices.
- Do not make `muse serve`/MSP a prerequisite unless implementation evidence proves headless `muse exec --session-id` cannot satisfy the accepted lifecycle; that finding routes back to Project Definition.
- Do not persist raw Muse trajectory/session material or runtime IDs into Project Workflow durable state.
