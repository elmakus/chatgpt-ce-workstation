# M01-T05 — Make PR macOS ad-hoc package verification self-consistent

## Milestone

M01

## Depends on

- M01-T04

## Authority slice

- `implementation/reviews/dual-native-upstreams-pr2-codesign-publication-failure-2026-09-18.md`
- M01 publication requirement: PR publication artifact must be verifiably buildable without weakening accepted routing/auth behavior.
- Existing `launcher/scripts/package.cjs` security boundary: credentialed signing material must not be enabled or exposed merely because CI is running for a pull request.

## Outcome

PR macOS packaging must exercise the repository's existing ad-hoc-signing verification path consistently instead of having Electron Builder suppress signing because the event is `pull_request`.

## Included scope

- Minimal PR/macOS no-credential signing behavior needed for `bun run app:package` to produce an ad-hoc-signed app that passes the existing `codesign --verify --deep --strict` check.
- Tests or source comments needed to make that behavior durable.

## Excluded scope

- No changes to Muse/Codex-LB/ChatGPT Web routing.
- No credentialed release-signing redesign.
- No new signing secrets, certificates, repository secrets, or secret exposure to pull requests.
- No weakening/removal of the existing macOS archive signature verification.

## Acceptance

1. When packaging macOS with neither `CSC_LINK` nor `CSC_NAME`, PR CI permits Electron Builder to use the already-selected ad-hoc identity `-` rather than skipping signing.
2. Credentialed signing behavior is not broadened for pull requests.
3. `bun run app:package` succeeds on the macOS PR job and the existing `codesign --verify --deep --strict` verification succeeds.
4. PR #2 CI is GREEN for the corrected subject, or any remaining RED is shown by exact evidence to be unrelated to this bounded correction.
5. The implementation is independently reviewed because the correction touches a signing/security-sensitive CI boundary.

## Required checks

- Static diff/source readback.
- PR #2 GitHub Actions readback, including macOS package step and overall workflow state.
- Independent review on the exact corrected subject.

## Review

REQUIRED — signing/security-sensitive CI boundary.
